第一章 数理逻辑

1.1 命题与五种基本联结词

  1. 命题（Proposition）
    • 定义：非真即假的陈述句称为命题。判断结果为真的称为真命题（真值记为 1 或 T），判断结果为假的称为假命题（真值记为 0 或 F）。疑问句、祈使句、感叹句以及真值随变量变化的开语句（如 x > 3）均不是命题。
    • 分类：不能再分解为更简单命题的称为原子命题（简单命题）；由原子命题通过逻辑联结词组合而成的称为复合命题。
  2. 五种基本逻辑联结词
    • 否定（¬P）：当 P 为 1 时，¬P 为 0；当 P 为 0 时，¬P 为 1。
    • 合取（P ∧ Q，与）：仅当 P 与 Q 同时为 1 时，P ∧ Q 为 1；否则为 0。
    • 析取（P ∨ Q，或）：仅当 P 与 Q 同时为 0 时，P ∨ Q 为 0；只要有一个为 1 即为 1（可兼或）。
    • 蕴涵（P → Q，如果 P 则 Q）：P 称为前件，Q 称为后件。仅当“前件 P 为 1 且后件 Q 为 0”时，P → Q 为 0；当 P 为 0 时，无论 Q 取何值，P → Q 恒为 1（善意推定）。
    • 等价（P ↔ Q，当且仅当）：当 P 与 Q 真值相同（同为 1 或同为 0）时，P ↔ Q 为 1；真值不同时为 0。
    • 联结词运算优先级（由高到低）：括号 () → 否定 ¬ → 合取 ∧ → 析取 ∨ → 蕴涵 → → 等价 ↔。

1.2 命题公式、等值演算与主范式

  1. 命题公式的三种类型
    • 重言式（永真式，Tautology）：在所有可能的真值赋值下，公式的真值恒为 1。
    • 矛盾式（永假式，Contradiction）：在所有可能的真值赋值下，公式的真值恒为 0。
    • 可满足式：至少存在一组赋值使公式的真值为 1（重言式也是可满足式；非矛盾式即为可满足式）。
  2. 核心等值式定律（A ⇔ B 表示 A ↔ B 为重言式）
    • 双重否定律：¬¬A ⇔ A
    • 交换律与结合律：A ∨ B ⇔ B ∨ A ， A ∧ B ⇔ B ∧ A
    • 分配律：A ∨ (B ∧ C) ⇔ (A ∨ B) ∧ (A ∨ C) ， A ∧ (B ∨ C) ⇔ (A ∧ B) ∨ (A ∧ C)
    • 德摩根律（De Morgan）：¬(A ∨ B) ⇔ ¬A ∧ ¬B ， ¬(A ∧ B) ⇔ ¬A ∨ ¬B
    • 吸收律：A ∨ (A ∧ B) ⇔ A ， A ∧ (A ∨ B) ⇔ A
    • 同一律与零律：A ∨ 0 ⇔ A ， A ∧ 1 ⇔ A ； A ∨ 1 ⇔ 1 ， A ∧ 0 ⇔ 0
    • 排中律与矛盾律：A ∨ ¬A ⇔ 1 ， A ∧ ¬A ⇔ 0
    • 蕴涵等值式（消去 → 的核心公式）：A → B ⇔ ¬A ∨ B
    • 假言易位（逆否命题等值）：A → B ⇔ ¬B → ¬A
    • 等价等值式（消去 ↔ 的核心公式）：A ↔ B ⇔ (A → B) ∧ (B → A) ⇔ (A ∧ B) ∨ (¬A ∧ ¬B)
  3. 析取范式（DNF）与合取范式（CNF）
    • 简单析取式：仅由命题变元或其否定通过 ∨ 构成的公式（如 P ∨ ¬Q）；简单合取式：仅由命题变元或其否定通过 ∧ 构成的公式（如 P ∧ ¬Q）。
    • 析取范式：由有限个简单合取式通过析取 ∨ 组成的公式，形如 (A1 ∧ A2) ∨ (B1 ∧ B2)。
    • 合取范式：由有限个简单析取式通过合取 ∧ 组成的公式，形如 (A1 ∨ A2) ∧ (B1 ∨ B2)。
  4. 极小项、极大项与主析取/主合取范式（唯一标准形式）
    • 设命题公式含有 n 个命题变元（共有 2^n 组赋值）：
    • 极小项（mi）：包含全部 n 个变元的简单合取式，且仅有对应二进制下标 i 的那一组赋值使其真值为 1（编码规则：赋值为 1 的变元取原形，赋值为 0 的变元取否定，中间用 ∧ 连接）。
    • 极大项（Mi）：包含全部 n 个变元的简单析取式，且仅有对应二进制下标 i 的那一组赋值使其真值为 0（编码规则：赋值为 0 的变元取原形，赋值为 1 的变元取否定，中间用 ∨ 连接）。性质：¬mi ⇔ Mi。
    • 主析取范式：完全由极小项析取（∨）构成的公式，包含了使原公式真值为 1（成真赋值） 的所有极小项。
    • 主合取范式：完全由极大项合取（∧）构成的公式，包含了使原公式真值为 0（成假赋值） 的所有极大项。
    • 主析取范式与主合取范式的互补转换：若含 3 个变元（下标全集为 {0, 1, 2, 3, 4, 5, 6, 7}）的公式 A 的主析取范式为 m1 ∨ m3 ∨ m5（记作 Σ(1, 3, 5)），则其成假赋值下标必为剩余补集，可直接写出主合取范式为 M0 ∧ M2 ∧ M4 ∧ M6 ∧ M7（记作 Π(0, 2, 4, 6, 7)）。

1.3 命题逻辑的推理理论

设前提集合为 {A1, A2, ..., Ak}，结论为 B。若蕴涵式 (A1 ∧ A2 ∧ ... ∧ Ak) → B 为重言式，则称由前提推出结论 B 的推理是有效的（正确的），记作 A1 ∧ A2 ∧ ... ∧ Ak ⇒ B。

  1. 常用基本推理定律（永真蕴涵式）
    • 附加律：A ⇒ (A ∨ B)
    • 化简律：(A ∧ B) ⇒ A
    • 假言推理（分离规则 MP）：(A → B) ∧ A ⇒ B
    • 拒取式（MT）：(A → B) ∧ ¬B ⇒ ¬A
    • 析取三段论（DS）：(A ∨ B) ∧ ¬A ⇒ B
    • 假言三段论（HS）：(A → B) ∧ (B → C) ⇒ (A → C)
    • 构造性二难：(A → B) ∧ (C → D) ∧ (A ∨ C) ⇒ (B ∨ D)
  2. 形式证明的三种方法
    • 直接证明法：从前提集合出发，逐步应用等值式（T 规则）与推理定律（P 规则）推导出结论 B。
    • 附加前提证明法（CP 规则）：若需要证明的结论本身是一个蕴涵式 C → D，由于 (A → (C → D)) ⇔ ((A ∧ C) → D)，可将结论的前件 C 作为附加前提加入前提集合，然后只需推导出后件 D 即可。
    • 归谬法（反证法）：将结论的否定 ¬B 作为附加前提加入前提集合，若能推导出矛盾式 R ∧ ¬R（即 0），则证明原推理有效。

1.4 一阶谓词逻辑

命题逻辑将原子命题视为不可拆分的整体，无法表达“凡人皆有一死，苏格拉底是人，所以苏格拉底会死”这类内部性质推理。一阶谓词逻辑引入了个体词、谓词与量词：

  1. 个体词、谓词与量词符号化规则
    • 个体词：所研究对象（具体的称为个体常项 a, b, c；泛指的称为个体变项 x, y, z；个体变项的取值范围称为个体域 / 论域 D）。
    • 谓词：刻画个体性质或个体间关系的词（如 F(x) 表示 x 是人，G(x) 表示 x 会死）。
    • 全称量词（∀x，对任意 x）与存在量词（∃x，存在某个 x）的标准符号化模板（必考）：
      • 当使用全集个体域时，必须引入特性谓词 F(x) 限定范围：
      • 全称量词 ∀x 后面的特性谓词必须作为蕴涵式 → 的前件：“所有的人都会死” 符号化为 ∀x (F(x) → G(x))（绝对不能写成 ∀x (F(x) ∧ G(x))，后者含义变成了“宇宙间万物既是人又会死”）。
      • 存在量词 ∃x 后面的特性谓词必须作为合取式 ∧ 的合取项：“有的人聪明” 符号化为 ∃x (F(x) ∧ H(x))（绝对不能写成 ∃x (F(x) → H(x))，否则只要宇宙间存在一个非人个体 F(a)=0，该式就恒为真）。
  2. 一阶逻辑核心等值式与前束范式
    • 量词否定等值式：¬∀x A(x) ⇔ ∃x ¬A(x) ， ¬∃x A(x) ⇔ ∀x ¬A(x)
    • 量词分配律：
      • 全称量词对合取 ∧ 分配：∀x (A(x) ∧ B(x)) ⇔ ∀x A(x) ∧ ∀x B(x)（对析取 ∨ 不分配）。
      • 存在量词对析取 ∨ 分配：∃x (A(x) ∨ B(x)) ⇔ ∃x A(x) ∨ ∃x B(x)（对合取 ∧ 不分配）。
    • 前束范式（Prenex Normal Form）：通过换名规则与量词辖域扩张，将所有量词全部移到公式最前端，且每个量词的辖域都延伸到整个公式末尾，形如 Q1x1 Q2x2 ... Qkxk B。
  3. 量词消去与引入的四大推理规则（先后顺序约束）
    • 全称指定规则（US）：∀x A(x) ⇒ A(y) 或 A(c)（对所有成立，则对任意指定个体成立）。
    • 存在指定规则（ES）：∃x A(x) ⇒ A(c)（核心限制：若同一个证明中既有存在量词又有全称量词需要指定为同一个常项 c，必须先执行 ES 存在指定，再执行 US 全称指定，因为 c 是使 A(x) 成立的特定个体，不能用之前已经出现过的常项）。
    • 全称推广规则（UG）：A(y) ⇒ ∀x A(x)（要求 y 是任意自由个体变项，未在前提中自由出现）。
    • 存在推广规则（EG）：A(c) ⇒ ∃x A(x)。

第二章 集合与二元关系

2.1 集合的基本运算与幂集

  1. 集合的基本运算
    • 并集（A ∪ B）、交集（A ∩ B）、差集（相对补，A - B）：属于 A 但不属于 B 的元素集合。
    • 对称差（A ⊕ B）：属于 A 或属于 B，但不同时属于两者的元素集合： A ⊕ B = (A - B) ∪ (B - A) = (A ∪ B) - (A ∩ B)
  2. 幂集（Power Set）
    • 定义：集合 A 的所有子集所组成的集合称为 A 的幂集，记作 P(A)，即 P(A) = { x | x ⊆ A }。
    • 基数公式：若有限集合 A 含有 n 个元素（|A| = n），则其幂集 P(A) 含有 2^n 个元素（|P(A)| = 2^n）。注意空集 ∅ ∈ P(A) 且 ∅ ⊆ P(A)。
  3. 容斥原理（包含排斥原理）
    • 两个有限集合并集的元素个数：|A ∪ B| = |A| + |B| - |A ∩ B|
    • 三个有限集合并集的元素个数：|A ∪ B ∪ C| = |A| + |B| + |C| - |A ∩ B| - |A ∩ C| - |B ∩ C| + |A ∩ B ∩ C|

2.2 笛卡尔积与二元关系的表示

  1. 有序对与笛卡尔积（Cartesian Product）
    • 有序对 <x, y>：具有先后次序的两个元素，<x, y> = <u, v> 当且仅当 x = u 且 y = v。
    • 笛卡尔积（A × B）：A × B = { <x, y> | x ∈ A ∧ y ∈ B }。笛卡尔积不满足交换律，也不满足结合律，但对并、交运算满足分配律。
    • 元素个数：若 |A| = m, |B| = n，则 |A × B| = m × n。
  2. 二元关系的定义与数量
    • 定义：笛卡尔积 A × B 的任意一个子集 R（R ⊆ A × B）都称为从 A 到 B 的一个二元关系；当 A = B 时，称 R ⊆ A × A 为集合 A 上的二元关系。
    • 关系总数：因为 |A × B| = m × n，其子集个数（即幂集元素个数）为 2^(m × n)，故从 A 到 B 共有 2^(m × n) 种不同的二元关系（集合 A 上共有 2^(n^2) 种二元关系）。
    • 三种特殊关系：空关系 ∅、全域关系 EA = A × A、恒等关系 IA = { <x, x> | x ∈ A }。
  3. 关系的表示与基本运算
    • 表示方法：集合枚举法、关系矩阵 M_R（若 <xi, xj> ∈ R 则 m_ij = 1，否则为 0）、关系图 G_R（有向图）。
    • 定义域 dom R（所有有序对第 1 元素集合）与值域 ran R（所有有序对第 2 元素集合）。
    • 逆关系（R^-1）：将 R 中所有有序对颠倒顺序，R^-1 = { <y, x> | <x, y> ∈ R }（对应关系矩阵转置 M^T，关系图所有箭头反向）。
    • 关系的右复合（R ◦ S）：R ◦ S = { <x, z> | ∃y (<x, y> ∈ R ∧ <y, z> ∈ S) }（对应关系矩阵做布尔矩阵乘法，其中加法按逻辑或 1 + 1 = 1 计算）。

2.3 二元关系的五种基本性质

设 R 为非空集合 A 上的二元关系，其五种基本性质的定义及在关系矩阵 M、关系图 G 上的判定特征如下：

性质名称 逻辑形式定义 关系矩阵 M 的特征 关系图 G 的特征
1. 自反性 (Reflexive) ∀x (x ∈ A → <x, x> ∈ R) 主对角线元素全为 1 每个顶点都有自环
2. 反自反性 (Irreflexive) ∀x (x ∈ A → <x, x> ∉ R) 主对角线元素全为 0 每个顶点都无自环
3. 对称性 (Symmetric) ∀x∀y (<x, y> ∈ R → <y, x> ∈ R) 对称矩阵（M = M^T） 任意两个不同顶点间若有有向边，必为成对双向边
4. 反对称性 (Antisymmetric) ∀x∀y (<x, y> ∈ R ∧ <y, x> ∈ R → x = y) 若 i ≠ j 且 m_ij = 1，则必有 m_ji = 0 任意两个不同顶点间若有有向边，只能是单向边
5. 传递性 (Transitive) ∀x∀y∀z (<x, y> ∈ R ∧ <y, z> ∈ R → <x, z> ∈ R) 矩阵布尔平方满足 M^2 ⊆ M 若从 x 到 y 有边且从 y 到 z 有边，则必有从 x 到 z 的直达边
  • 易错点说明：
    1. “非自反”不等于“反自反”：若主对角线上既有 1 又有 0，则该关系既不是自反的，也不是反自反的。
    2. “对称”与“反对称”不是非此即彼的：例如恒等关系 IA（只有主对角线为 1，其余全为 0）和空关系 ∅，同时满足对称性与反对称性。

2.4 关系的闭包（Closure）

给定集合 A 上的关系 R，若希望在 R 中添加最少数量的有序对，使其具备自反性、对称性或传递性，所得的新关系分别称为 R 的自反闭包 r(R)、对称闭包 s(R) 和传递闭包 t(R)：

  1. 自反闭包 r(R)
    • 公式：r(R) = R ∪ IA
    • 求法：将关系矩阵 M 的主对角线元素全部改为 1；关系图中为所有缺少自环的顶点补上自环。
  2. 对称闭包 s(R)
    • 公式：s(R) = R ∪ R^-1
    • 求法：将关系矩阵 M 与其转置 M^T 按位逻辑或（使矩阵关于主对角线对称补 1）；关系图中将所有单向边补成双向边。
  3. 传递闭包 t(R) 与 Warshall 算法
    • 公式：t(R) = R ∪ R^2 ∪ R^3 ∪ ... ∪ R^n（其中 n = |A|）。
    • Warshall 算法（在 n 阶关系矩阵 M 上直接求传递闭包，共迭代 k = 1, 2, ..., n 步）：
      • 第 k 步：以第 k 列和第 k 行为桥梁——扫描第 k 列，找出第 k 列中所有值为 1 的行号 i（即 M[i][k] == 1）；
      • 将第 k 行的元素逐位逻辑或（加）到第 i 行上（即对所有 j 更新 M[i][j] = M[i][j] ∨ M[k][j]）；
      • 依次令 k 从 1 执行到 n，最终得到的矩阵即为传递闭包 t(R) 的关系矩阵。

2.5 等价关系与偏序关系

  1. 等价关系（Equivalence Relation）与商集、划分
    • 定义：若非空集合 A 上的关系 R 同时满足自反性、对称性、传递性，则称 R 为 A 上的等价关系（如整数集上的“模 n 同余关系”）。
    • 等价类（[x]_R）：所有与元素 x 具有等价关系的 A 中元素构成的集合，即 [x]_R = { y ∈ A | <x, y> ∈ R }。两个等价类要么完全相等，要么交集为空（互不相交）。
    • 商集（A / R）：以 R 的所有不同等价类作为元素构成的集合，称为 A 关于 R 的商集：A / R = { [x]_R | x ∈ A }。
    • 等价关系与集合划分的一一对应：集合 A 上的每一个等价关系 R，其商集 A / R 都是 A 的一个划分（Partition，将 A 切分为若干个非空且两两不相交的子集块）；反之，A 的任意一个划分也唯一确定一个等价关系（每个划分块内部的元素两两全连通，块内构成完全子图）。
  2. 偏序关系（Partial Order）与哈斯图（Hasse Diagram）
    • 定义：若非空集合 A 上的关系 R 同时满足自反性、反对称性、传递性，则称 R 为 A 上的偏序关系，常记作 ≼，二元组 <A, ≼> 称为偏序集（如正整数集上的“小于等于 ≤”、“整除关系 |”，幂集上的“包含关系 ⊆”）。
    • 全序关系（线序）：若偏序集 A 中任意两个元素都可比较（即必有 x ≼ y 或 y ≼ x），则称为全序集（如实数大小关系 ≤）；而整除关系和集合包含关系中存在不可比较的元素（如 2 与 3 互不整除），故仅是偏序而非全序。
    • 哈斯图的画法规则（利用偏序的三个性质极简表示关系图）：
      1. 因具有自反性，省去所有顶点的自环；
      2. 因具有反对称性，规定若 x ≼ y（且 x ≠ y），将 y 画在 x 的上方，省去所有边上的箭头（默认方向自下而上）；
      3. 因具有传递性，省去所有可通过传递推导出的跨层边，仅在直接“盖住”的两个元素之间连一条无向线段。
  3. 偏序集中的八类特殊元素（必考辨析） 设 <A, ≼> 为偏序集，B ⊆ A 为其非空子集：
    • 极小元与极大元（在 B 内部找，一定存在，可能不唯一）：
      • 极小元：B 中没有比它更小的元素（在 B 的哈斯图中下方没有任何连线的顶点）。
      • 极大元：B 中没有比它更大的元素（在 B 的哈斯图中上方没有任何连线的顶点）。
    • 最小元与最大元（在 B 内部找，不一定存在，一旦存在必唯一）：
      • 最小元：B 中一个比 B 内所有其他元素都小（都与它可比且在它上方）的元素。判定窍门：只有当 B 的极小元唯一时，该唯一极小元才是最小元；若极小元有多个，则最小元不存在。
      • 最大元：同理，只有当 B 的极大元唯一时，该唯一极大元才是最大元。
    • 上界、下界与上确界（最小上界）、下确界（最大下界）（在整个大集合 A 中找）：
      • 上界：大集合 A 中能够排在子集 B 所有元素上方（或等于）的元素集合。
      • 最小上界（上确界，sup B）：所有上界组成的集合中的最小元（若上界集合没有唯一最小元，则上确界不存在）。
      • 下界：大集合 A 中能够排在子集 B 所有元素下方（或等于）的元素集合。
      • 最大下界（下确界，inf B）：所有下界组成的集合中的最大元。

第三章 函数与集合基数

3.1 函数的定义与三类特殊性质

  1. 函数的关系定义与计数
    • 定义：设 A, B 为非空集合，若从 A 到 B 的二元关系 f 满足以下两个条件，则称 f 为从 A 到 B 的函数（或映射），记作 f: A → B：
      1. 像的存在性（处处有定义）：dom f = A，即 A 中每一个元素 x 都必须参与映射；
      2. 像的唯一性（单值性）：对任意 x ∈ A，在 B 中有且仅有唯一的一个 y 使得 <x, y> ∈ f，记作 f(x) = y（允许“多对一”，绝不允许“一对多”）。
    • 从有限集 A 到 B 的函数总数：设 |A| = m, |B| = n，因为 A 中每个元素在 B 中都有 n 种独立选择，故共有 n^m 个不同的函数（对比：从 A 到 B 的二元关系总数为 2^(m × n)）。
  2. 单射、满射与双射
    • 单射（Injection，一对一映射）：
      • 定义：∀x1∀x2 ∈ A (x1 ≠ x2 → f(x1) ≠ f(x2))（或逆否形式 f(x1) = f(x2) → x1 = x2），即不同的自变量必映射到不同的函数值。
      • 存在条件与计数：仅当 |A| = m ≤ |B| = n 时才存在单射；单射函数总数为排列数 P(n, m) = n! / (n - m)!。
    • 满射（Surjection，映上映射）：
      • 定义：ran f = B（即 ∀y ∈ B ∃x ∈ A (f(x) = y)），即值域 B 中的每一个元素都至少有一个原像。
      • 存在条件与计数：仅当 |A| = m ≥ |B| = n 时才存在满射；满射函数总数为 n! × S(m, n)（其中 S(m, n) 为第二类斯特林数，表示将 m 个不同元素划分为 n 个非空无区别集合的方案数）。
    • 双射（Bijection，一一对应）：
      • 定义：若函数 f 既是单射又是满射，则称 f 为双射。
      • 存在条件与计数：仅当 |A| = |B| = n 时才存在双射；双射函数总数为全排列数 n!。

3.2 复合函数与逆函数

  1. 复合函数（左复合 g ◦ f）
    • 定义：设函数 f: A → B 且 g: B → C，则复合函数 g ◦ f: A → C 定义为对任意 x ∈ A，有： (g ◦ f)(x) = g(f(x)) （注意：函数复合默认采用左复合，即先作用右边的内层函数 f，再作用左边的外层函数 g；这与二元关系的右复合顺序相反）。
    • 函数复合的性质保持与逆推规律（常考）：
      • 正向保持：若 f 和 g 都是单射（或满射、双射），则复合函数 g ◦ f 必为单射（或满射、双射）。
      • 逆向推导（不对称性）：
        1. 若 g ◦ f 是单射，则内层函数 f 必为单射（外层函数 g 不一定是单射）；
        2. 若 g ◦ f 是满射，则外层函数 g 必为满射（内层函数 f 不一定是满射）；
        3. 若 g ◦ f 是双射，则内层函数 f 必为单射，且外层函数 g 必为满射。
  2. 逆函数（f^-1）
    • 存在充要条件：函数 f: A → B 的逆关系 f^-1 仍然构成从 B 到 A 的函数，当且仅当 f 是双射。
    • 基本性质：若 f: A → B 是双射，则 f^-1: B → A 也是双射，且满足： f^-1 ◦ f = IA（A 上的恒等函数）， f ◦ f^-1 = IB（B 上的恒等函数）。

3.3 集合的等势与基数

  1. 集合的等势（Equinumerosity）
    • 定义：设 A, B 为两个集合，若存在从 A 到 B 的双射函数 f: A → B，则称集合 A 与 B 等势（基数相同），记作 A ≈ B。等势关系满足自反性、对称性与传递性。
    • 无限集的特征定义：一个集合是无限集，当且仅当它能与自己的某个真子集等势（如自然数集 N 与正偶数集 {2, 4, 6, ...} 通过双射 f(n) = 2n 等势）。
  2. 可数集（Countable Set）与不可数集（Uncountable Set）
    • 可数集（基数记作阿列夫零 ℵ0）：凡与自然数集 N = {0, 1, 2, ...} 等势的无限集合统称为可数集（可列集）。
      • 常见可数集：自然数集 N、整数集 Z、有理数集 Q、代数数集，以及有限个或可数无穷多个可数集的并集、笛卡尔积 N × N。
    • 不可数集（连续统基数记作 ℵ 或 c）：不能与自然数集建立一一对应的无限集合。
      • 常见不可数集：实数集 R、无理数集、任意非退化实数区间 (a, b) 或 [a, b]（注：R ≈ (0, 1)，可通过正切函数 f(x) = tan(π(x - 1/2)) 建立双射）、自然数集的幂集 P(N)。
    • 康托尔（Cantor）定理：对任意集合 A，其幂集的基数严格大于原集合的基数（即 |A| < |P(A)|，不存在从 A 到 P(A) 的满射或双射）。特别地，自然数幂集的基数等于实数集的连续统基数：2^ℵ0 = ℵ > ℵ0。

第四章 图论与树

4.1 图的基本概念与握手定理

  1. 无向图、有向图与特殊图类
    • 基本概念：图 G = <V, E> 由非空顶点集 V（顶点数 |V| = n 称为图的阶）和边集 E（边数 |E| = m）组成。两端点重合的边称为自环；连接同一对顶点的多条无向边（或同向有向边）称为平行边（重边）。
    • 简单图（Simple Graph）：既不含自环、也不含平行边的图（图论定理默认均针对简单图）。
    • n 阶无向完全图（Kn）：任意两个不同顶点之间都有一条边相连的无向简单图。每个顶点的度数均为 n - 1，总边数为： m = C(n, 2) = n(n - 1) / 2 （n 阶有向完全图的边数为 n(n - 1)）。
    • k-正则图（k-Regular Graph）：每个顶点的度数都等于常数 k 的无向简单图（总边数 m = n × k / 2）。
    • 子图、生成子图与导出子图：若 V' ⊆ V 且 E' ⊆ E，称 G' = <V', E'> 为 G 的子图；若 V' = V（包含原图全部顶点），则称 G' 为 G 的生成子图（支撑子图）。
    • 补图（G_bar）：从完全图 Kn 中删去原图 G 的所有边后剩余的生成子图，满足 m(G) + m(G_bar) = n(n - 1) / 2。
  2. 顶点的度数与握手定理（Handshaking Lemma）
    • 无向图握手定理：无向图 G = <V, E> 中所有顶点的度数之和等于边数 m 的 2 倍（因为每条边恰好为两个端点各贡献 1 度）： Σ d(v) = 2m
    • 有向图握手定理：有向图 D = <V, E> 中所有顶点的入度之和等于出度之和，且等于总边数 m： Σ d+(v) = Σ d-(v) = m
    • 握手定理的重要推论：在任何无向图或有向图中，度数为奇数的顶点（奇度顶点）的个数必定是偶数。
  3. 二分图（二部图，Bipartite Graph）及其判定
    • 定义：若无向图 G = <V, E> 的顶点集 V 可以分割为两个互不相交的非空子集 V1 和 V2（V1 ∪ V2 = V 且 V1 ∩ V2 = ∅），使得图中每一条边的两个端点都分别属于 V1 和 V2（同一子集内部没有任何边），则称 G 为二分图。若 V1 中每个顶点与 V2 中每个顶点都有一条边相连，则称为完全二分图，记作 Kr,s（其中 r = |V1|, s = |V2|，总边数 m = r × s）。
    • 二分图的充要条件（必考定理）：一个无向图 G 是二分图，当且仅当 G 中不包含长度为奇数的回路（奇圈）。

4.2 通路、回路与图的连通性

  1. 通路（Walk）与回路（Closed Walk）的分类
    • 通路 / 回路：顶点与边交替出现的序列，起点与终点相同的通路称为回路，包含的边数称为长度。
    • 简单通路（迹，Trail）/ 简单回路（闭迹）：所有边互不重复的通路 / 回路（允许顶点重复）。
    • 初级通路（路径，Path）/ 初级回路（圈，Cycle）：所有顶点互不重复（从而边也必不重复）的通路 / 回路（初级回路仅起点与终点重合）。在 n 阶图中，任何初级通路长度不超过 n - 1，任何初级回路长度不超过 n。
  2. 无向图的连通性、割点与桥
    • 连通图与连通分支 p(G)：若无向图 G 中任意两个不同顶点之间都存在通路，则称 G 为连通图（p(G) = 1）；否则 G 被划分为若干个极大连通子图，每个极大连通子图称为一个连通分支。
    • 点割集与割点（Cut Vertex）：设 V' ⊂ V，若删去顶点集 V'（及关联的所有边）后使连通分支数增加（p(G - V') > p(G)），且删去 V' 的任何真子集都不能使连通分支数增加（极小性），则称 V' 为点割集。若点割集只有一个顶点 v，则称 v 为割点。
    • 边割集与割边（桥，Bridge）：设 E' ⊆ E，若删去边集 E' 后使连通分支数增加（p(G - E') > p(G)），且满足极小性，则称 E' 为边割集。若边割集只有一条边 e，则称 e 为割边（或桥）。判定定理：无向图中的一条边 e 是桥，当且仅当 e 不在图中的任何一个圈（初级回路）内。
  3. 有向图的三种连通性（由强到弱）
    • 强连通图（Strongly Connected）：有向图中任意一对顶点 u, v 之间双向都存在有向通路（既有 u → v 又有 v → u）。充要条件：图中存在一条经过所有顶点至少一次的有向回路。
    • 单向连通图（Unilaterally Connected）：有向图中任意一对顶点 u, v 之间至少有一个方向存在有向通路（u → v 或 v → u）。充要条件：图中存在一条经过所有顶点至少一次的有向通路。
    • 弱连通图（Weakly Connected）：将有向图的所有有向边替换为无向边后，所得的基图（底图）是无向连通图。
    • 强弱推导关系：强连通图 ⇒ 单向连通图 ⇒ 弱连通图（反之不成立）。
  4. 邻接矩阵 A 的幂与通路总数计算
    • 设图 G 的邻接矩阵为 A = (a_ij)_n×n，将 A 进行普通矩阵乘法得到 l 次幂矩阵 A^l = (a_ij^(l))，则其中第 i 行第 j 列的元素 a_ij^(l) 恰好等于从顶点 vi 到顶点 vj 长度为 l 的通路总数（其中主对角线元素 a_ii^(l) 等于经过顶点 vi 且长度为 l 的回路总数）。

  1. 欧拉图的充要判定定理（一笔画定理）
    • 无向图：
      • 无向图 G 是欧拉图（含欧拉回路） ⇔ G 连通（无孤立点），且所有顶点的度数全为偶数（奇度顶点个数为 0）。
      • 无向图 G 是半欧拉图（含欧拉通路但无欧拉回路） ⇔ G 连通，且恰有 2 个奇度顶点（欧拉通路必以这两个奇度顶点分别作为起点和终点）。
    • 有向图：
      • 有向图 D 是有向欧拉图 ⇔ D 的基图连通，且所有顶点的入度等于出度（d+(v) = d-(v)）。
      • 有向图 D 是有向半欧拉图 ⇔ D 的基图连通，且恰有一个顶点出度比入度大 1（起点）、恰有一个顶点入度比出度大 1（终点），其余所有顶点入度均等于出度。
  2. 哈密顿图的必要条件与充分条件
    • 必要条件（考题中用于证明“某个图不是哈密顿图”的核心武器）：
      • 定理：若无向图 G = <V, E> 是哈密顿图，则对于顶点集 V 的任意非空真子集 V1，从 G 中删去 V1 后所得剩余子图的连通分支数 p(G - V1) 必定满足： p(G - V1) ≤ |V1| （若仅含哈密顿通路，则满足 p(G - V1) ≤ |V1| + 1）。
      • 推论 1：若图中存在割点（即取 |V1| = 1 时 p(G - V1) ≥ 2 > 1）或桥，则该图一定不是哈密顿图。
      • 推论 2（二分图判定）：设二分图 G = <V1, V2, E>（不妨设 |V1| ≤ |V2|），由于哈密顿回路必须在 V1 和 V2 之间交替穿梭：
        • 若 |V1| ≠ |V2|，则 G 一定不是哈密顿图；
        • 若 |V2| - |V1| ≥ 2，则 G 连哈密顿通路都不存在（例如 K2,4 既无哈密顿回路也无哈密顿通路；K2,3 无哈密顿回路但有哈密顿通路）。
    • 充分条件（Ore 定理与 Dirac 定理，针对 n ≥ 3 的无向简单图）：
      • 若图中任意两个不相邻顶点 u, v 的度数之和满足 d(u) + d(v) ≥ n - 1，则 G 中必存在哈密顿通路；
      • 若任意两个不相邻顶点 u, v 的度数之和满足 d(u) + d(v) ≥ n（特别地，若每个顶点的度数都满足 d(v) ≥ n / 2），则 G 必为哈密顿图。

4.4 平面图、无向树与最优二叉树

  1. 平面图（Planar Graph）与欧拉公式
    • 平面图与面的次数定理：能画在平面上使任何两条边除端点外均不相交的图称为平面图。平面图的边将平面划分为若干个区域，称为面（Face，包含 1 个无限面 / 外部面和若干个有限面 / 内部面）。包围面 Ri 的闭回路长度称为该面的次数 deg(Ri)（其内部悬挂的桥计算 2 次）。所有面的次数之和等于边数的 2 倍： Σ deg(Ri) = 2m
    • 平面图欧拉公式：设 G 是具有 n 个顶点、m 条边、r 个面的连通平面图，则恒有： n - m + r = 2 （若平面图 G 有 k 个连通分支，则广义欧拉公式为 n - m + r = k + 1）。
    • 简单平面图的边数上限不等式（用于证明非平面图）：
      • 设 G 为 n ≥ 3 的连通简单平面图，因无自环和平行边，每个面至少由 3 条边围成（deg(Ri) ≥ 3），故 2m = Σ deg(Ri) ≥ 3r，代入 r = 2 - n + m 可得： m ≤ 3n - 6
      • 若连通简单平面图 G 中不含三角形（每个面至少由 4 条边围成，deg(Ri) ≥ 4，例如所有二分图），则同理可得更紧的上限： m ≤ 2n - 4
    • 库拉托夫斯基（Kuratowski）定理：一个图是平面图，当且仅当它不包含与 K5（5 阶完全图，n=5, m=10 > 3×5-6=9）或 K3,3（完全二分图，n=6, m=9 > 2×6-4=8）同胚（或可收缩）的子图。K5 是顶点数最少的非平面图，K3,3 是边数最少的非平面图。
    • 平面图的对偶图（G*）與着色定理：
      • 对偶图的顶点数 n* = r（原图面数）、边数 m* = m（原图边数）、面数 r* = n（当原图连通时）。
      • 四色定理：任何平面图的顶点着色数（相邻顶点颜色不同所需的最少颜色数 χ(G)）均满足 χ(G) ≤ 4。

  1. 无向树的六个等价定义与最小生成树
    • 无向树（Tree）：连通且不含回路的无向图（多个互不相交的无向树构成森林；树中度数为 1 的顶点称为树叶，度数 ≥ 2 的顶点称为分支点 / 内点）。
    • n 阶无向树 T = <V, E> 的六个等价充要条件（核心恒等式：边数 m = n - 1）：
      1. G 连通且无回路；
      2. G 无回路且 m = n - 1；
      3. G 连通且 m = n - 1；
      4. G 无回路，但在任意两个不相邻顶点间增加一条新边，就会产生唯一的一条初级回路；
      5. G 连通，但删去任意一条边后图就不再连通（即树中的每一条边都是桥）；
      6. G 中任意两个顶点之间存在唯一的初级通路。
    • 树叶个数计算题型：利用边数 m = n - 1 与握手定理 Σ d(v) = 2m = 2(n - 1) 联立求解。
    • 生成树与最小生成树（MST）：
      • 连通无向图 G 的生成子图若是一棵树，则称为 G 的生成树（含 n - 1 条树枝，其余不在生成树中的 m - n + 1 条边称为弦 / 连枝，也等于基本回路系统中的基本回路个数）。
      • Kruskal 算法（避圈法）：将所有边按权值从小到大排序，依次选入不与已选边构成回路的最小权边，直到选满 n - 1 条树枝。
  2. 根树、正则 m 叉树与最优二叉树（哈夫曼树）
    • 正则 m 叉树（完全 m 叉树）的分支点与树叶数量关系： 若一棵正则 m 叉树（每个分支点都恰好有 m 个儿子）共有 i 个分支点和 t 片树叶，则总顶点数 n = i + t，总边数 m_edge = m × i = n - 1 = i + t - 1，化简即得必考公式： (m - 1) × i = t - 1 特别地，对于正则二叉树（m = 2），恒有：树叶数 t = i + 1（叶子数永远比二分支节点数多 1）。
    • 带权路径长度（WPL）与哈夫曼（Huffman）算法：
      • 给定 t 个叶节点的权值 {w1, w2, ..., wt}，设叶节点 wi 到根节点的路径长度（层数，根为第 0 层）为 li，则树的带权路径长度为： WPL = Σ (wi × li)（数值上也等于所有非叶分支节点的权值之和）。
      • 哈夫曼构造法：每次从当前森林中选出权值最小的两棵树作为左右子树合并为一棵新树，新树根节点的权值为左右子树根权值之和；重复合并 t - 1 次后得到的正则二叉树即为使 WPL 最小的最优二叉树（哈夫曼树）。由左分支标 0、右分支标 1 即可得到每个叶节点的最佳前缀码。

第五章 代数结构

5.1 二元运算与特殊元素

  1. 代数系统与二元运算的基本性质
    • 代数系统（Algebraic System）：非空集合 S（称为载体）连同定义在 S 上的若干个封闭运算 f1, f2, ..., fk 所组成的系统，记作 <S, f1, f2, ..., fk>。
    • 二元运算的封闭性（Closure）：对任意 x, y ∈ S，运算结果 x * y 都有定义且唯一地属于集合 S（运算表中所有单元格的值均属于 S）。
    • 基本运算律：
      • 交换律：∀x, y ∈ S (x * y = y * x)（在运算表中的特征：矩阵关于主对角线对称）。
      • 结合律：∀x, y, z ∈ S ((x * y) * z = x * (y * z))。
      • 幂等律：∀x ∈ S (x * x = x)（满足 x * x = x 的单个元素 x 称为幂等元；在运算表中的特征：主对角线元素与表头元素一一相同）。
      • 分配律：运算 * 对 ◦ 满足左分配律 x * (y ◦ z) = (x * y) ◦ (x * z) 与右分配律 (y ◦ z) * x = (y * x) ◦ (z * x)。
      • 吸收律：若 * 和 ◦ 都满足交换律，且 x * (x ◦ y) = x 及 x ◦ (x * y) = x，则称两运算互相满足吸收律。
      • 消去律：对元素 a ∈ S（a 不为零元），若 ∀x, y ∈ S (a * x = a * y → x = y) 且 (x * a = y * a → x = y)，则称 a 是可消去的（在运算表中的特征：每行、每列均无重复元素）。

5.2 半群、独异点与群

  1. 代数系统的五层公理递进关系 根据二元运算 * 所满足公理的由弱到强，代数系统 <G, *> 依次演进为以下五类结构：
    1. 广群（Magma）：仅满足二元运算封闭性。
    2. 半群（Semigroup）：广群 + 结合律（如正整数加法 <Z+, +>、n 阶矩阵乘法）。
    3. 独异点（含幺半群，Monoid）：半群 + 存在单位元（幺元 e）（如自然数加法 <N, +, 0>、字符串连接运算）。
    4. 群（Group）：独异点 + 每个元素都存在逆元 x^-1（如整数加法群 <Z, +, 0>、非零实数乘法群 <R*, ×, 1>、n 阶可逆矩阵乘法群）。
    5. 阿贝尔群（交换群，Abelian Group）：群 + 交换律（如 <Z, +> 是阿贝尔群，而矩阵乘法群不是阿贝尔群）。

  1. 群的基本性质与元素的阶
    • 群中无零元：阶数 |G| ≥ 2 的群中绝对不存在零元（因为零元 θ 与任何元素运算都得 θ ≠ e，不可能有逆元）。
    • 群中消去律恒成立：对任意 a, b, c ∈ G，由 a * b = a * c 左乘 a^-1 即得 b = c；同理右消去律也成立。
    • 群中方程解唯一：方程 a * x = b 有唯一解 x = a^-1 * b，方程 y * a = b 有唯一解 y = b * a^-1。因此在有限群的运算表中，每一行、每一列都是群元素集合 G 的一个无重复全排列。
    • 穿脱法则（逆元性质）：对任意 a, b ∈ G，恒有 (a * b)^-1 = b^-1 * a^-1（注意顺序颠倒），且 (a^-1)^-1 = a。
    • 群中幂等元唯一：群 G 中唯一的幂等元就是单位元 e（因为若 x * x = x = x * e，由消去律立得 x = e）。
    • 元素的阶（Order |a|）：设 a ∈ G，使 a^k = e 成立的最小正整数 k 称为元素 a 的阶，记作 |a| = k（若不存在这样的正整数，则称 a 为无限阶元）。
      • 核心性质 1：a^m = e 当且仅当 |a| 整除 m（即 |a| | m），且元素与它的逆元同阶（|a| = |a^-1|）。
      • 核心性质 2：若 |a| = n，则对任意正整数 k，幂元素 a^k 的阶为： |a^k| = n / gcd(k, n)
  2. 循环群（Cyclic Group）及其生成元
    • 定义：若群 G 中存在一个元素 g，使得 G 中任意元素都能表示为 g 的整数次幂（G = { g^k | k ∈ Z }），则称 G 为循环群，记作 G = <g>，称 g 为群 G 的生成元。任何循环群都满足交换律，故循环群必为阿贝尔群。
    • 两类标准循环群的生成元个数（必考）：
      1. 无限循环群（同构于整数加法群 <Z, +>）：有且仅有 2 个生成元，即 g 和 g^-1（在 <Z, +> 中对应 1 和 -1）。
      2. n 阶有限循环群（G = {e, g, g^2, ..., g^(n-1)}，同构于模 n 加法群 <Zn, +n>）：元素 g^r 是 G 的生成元，当且仅当 gcd(r, n) = 1（r 与 n 互质）。因此，n 阶循环群的生成元个数恰好等于欧拉函数 φ(n)（小于等于 n 且与 n 互质的正整数个数）。
  3. 子群（Subgroup）、陪集与拉格朗日（Lagrange）定理
    • 子群定义与一步判定法：设 H 是群 G 的非空子集，若 H 关于 G 的运算也构成群，则称 H 为 G 的子群，记作 H ≤ G。
      • 充要判定定理：H ≤ G ⇔ ∀a, b ∈ H (a * b^-1 ∈ H)（若 H 是有限非空子集，只需验证运算封闭性 ∀a, b ∈ H (a * b ∈ H) 即可保证 H 是子群）。
    • 陪集与拉格朗日定理（有限群核心定理）：
      • 设 H ≤ G，对任意 a ∈ G，集合 aH = { a * h | h ∈ H } 称为 H 的一个左陪集。所有左陪集构成群 G 的一个划分，且每个陪集的元素个数都等于 |H|。
      • 拉格朗日定理：设 G 是有限群，H 是 G 的子群，则子群 H 的阶（|H|）以及群中任意元素的阶（|a|）都必定整除群 G 的阶（|G|）： |G| = |H| × [G : H] （其中 [G : H] 为不同左陪集的个数，称为子群 H 在 G 中的指数）。
      • 重要推论：
        1. 素数阶群（|G| = p，p 为质数）必为循环群（进而必为阿贝尔群），且除平凡子群 {e} 和 G 外没有任何真子群，其中除单位元 e 以外的其余 p - 1 个元素全都是生成元。
        2. 小于等于 5 阶的群全部都是阿贝尔群；最小的非交换群（非阿贝尔群）是 6 阶三次对称群 S3。

5.3 格与布尔代数

  1. 格（Lattice）的偏序定义与代数定义
    • 偏序定义：设 <L, ≼> 是偏序集，若 L 中任意两个元素 {a, b} 都既有最小上界（上确界 sup{a, b}，记作并 a ∨ b）又有最大下界（下确界 inf{a, b}，记作交 a ∧ b），则称 <L, ≼> 为一个格（全序集、整除格 <Sn, |>、幂集格 <P(A), ⊆> 都是格）。
    • 代数定义：设 <L, ∧, ∨> 是具有两个二元运算的代数系统，若运算 ∧ 和 ∨ 满足以下三组定律（共 6 条等式），则构成格：
      1. 交换律：a ∧ b = b ∧ a ， a ∨ b = b ∨ a
      2. 结合律：(a ∧ b) ∧ c = a ∧ (b ∧ c) ， (a ∨ b) ∨ c = a ∨ (b ∨ c)
      3. 吸收律：a ∧ (a ∨ b) = a ， a ∨ (a ∧ b) = a
      • 性质：由结合律与吸收律可直接推导出幂等律（a ∧ a = a ， a ∨ a = a），且在格中恒有 a ≼ b ⇔ a ∧ b = a ⇔ a ∨ b = b。
  2. 分配格、有界格、有补格与布尔代数

  • 分配格（Distributive Lattice）：
    • 定义：在格 <L, ∧, ∨> 中，若运算 ∧ 和 ∨ 互相满足分配律： a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c) 且 a ∨ (b ∧ c) = (a ∨ b) ∧ (a ∨ c)，则称 L 为分配格（任何普通的格只满足分配不等式，不一定满足分配律）。
    • 分配格的哈斯图充要判定定理：一个格是分配格，当且仅当它不包含与五元钻石格（M3）或五元五边形格（N5）同构的子格（推论：所有全序集 / 链、所有小于 5 个元素的格都是分配格）。
  • 有界格与有补格（Complemented Lattice）：
    • 有界格：存在全下界 0（最小元，∀a (0 ≼ a)） 和全上界 1（最大元，∀a (a ≼ 1)） 的格，记作 <L, ∧, ∨, 0, 1>。任何有限格都是有界格。
    • 补元与有补格：在有界格中，若元素 a 和 b 满足 a ∧ b = 0 且 a ∨ b = 1，则称 a 与 b 互为补元（0 与 1 永远互为唯一补元）。若格中每一个元素都至少存在一个补元，则称为有补格。
    • 有界分配格中的补元唯一性：在一般的有界格中，一个元素的补元可能不存在，也可能不止一个（如五元钻石格 M3 中 a, b, c 两两互为补元）；但在有界分配格中，若某个元素存在补元，则其补元必定唯一。
  • 布尔代数（Boolean Algebra）：
    • 定义：既有补、又分配的有界格（即有补分配格）称为布尔代数，将每个元素 a 的唯一补元记为 a'，构成代数系统 <B, ∧, ∨, ', 0, 1>（命题公式等价类系统、集合幂集系统 <P(S), ∩, ∪, ~, ∅, S>、开关电路 {0, 1} 都是布尔代数）。
    • 有限布尔代数的结构定理（Stone 表示定理有限情形）： 任何有限布尔代数的元素个数必定是 2 的幂次 2^n（n ∈ Z+），且任意两个具有 2^n 个元素的有限布尔代数都同构于某个 n 元集合 S 的幂集布尔代数 <P(S), ∩, ∪, ~, ∅, S>。
    • 整除格 <Sn, |> 构成布尔代数的充要条件：设 Sn 为正整数 n 的所有正因子集合，偏序为整除关系 |，则 <Sn, |> 是布尔代数，当且仅当 n 的质因数分解中没有重复的质因子（即 n = p1 × p2 × ... × pk，每个质因子的指数均为 1，例如 S6, S10, S30 是布尔代数，而 S4, S12, S24 因含有平方因子 2^2 = 4 故不是有补格，从而不是布尔代数）。
