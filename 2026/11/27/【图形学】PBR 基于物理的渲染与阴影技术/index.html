本文围绕现代实时渲染中的物理光照与阴影算法，分为四个章节：辐射度量学基础与渲染方程、Cook-Torrance 微表面模型与金属度-粗糙度工作流、基于图像的光照（IBL）与 Split-Sum 近似、实时阴影技术（Shadow Map、PCF、PCSS 与 CSM 级联阴影）。

第 1 章：辐射度量学基础、BRDF 与渲染方程#

传统经验光照模型（Phong / Blinn-Phong）将漫反射与高光简单相加，不仅违反能量守恒定律（高光越强表面总亮度反而越亮，导致过曝塑料感），且材质参数在不同的环境光照下表现严重失真。基于物理的渲染（PBR）建立在严格的光学物理度量——辐射度量学（Radiometry）之上。

第 2 章：Cook-Torrance 微表面模型与金属度-粗糙度工作流#

2.1 Cook-Torrance 微表面镜面 BRDF 三大核心函数（D / F / G）#

微表面理论（Microfacet Theory）认为，宏观上看似平坦的粗糙表面，在微观尺度下是由无数个朝向各异的理想镜面微平面（Microfacets）组成的。当入射光方向为 l\mathbf{l}l、视线方向为 v\mathbf{v}v 时，根据反射定律，只有那些微观法线 m\mathbf{m}m 恰好等于半程向量 h=normalize⁡(l+v)\mathbf{h} = \operatorname{normalize}(\mathbf{l} + \mathbf{v})h=normalize(l+v) 的活性微平面，才能将光线 l\mathbf{l}l 镜面反射进眼睛 v\mathbf{v}v。据此导出 Cook-Torrance 镜面 BRDF 标准形式：

2.2 导体（金属）vs 电介质（非金属）与金属度工作流能量守恒#

现代渲染引擎通常采用 BaseColor（基础色 RGB）+ Metallic（金属度）+ Roughness（粗糙度） 参数化材质：

  1. 电介质（Dielectrics / 非金属，如塑料、木材、石材、皮肤，metallic=0\text{metallic} = 0metallic=0）：
    • 垂直基础反射率 F0F_0F0​ 较低且无色（通常在 0.02∼0.050.02 \sim 0.050.02∼0.05 之间，引擎取常数 float3(0.04, 0.04, 0.04)）。
    • 折射进入非金属内部的光线经次表面散射后重新穿出，形成带有 BaseColor 颜色的漫反射（Diffuse）。
  2. 导体（Conductors / 金属，如金、银、铜、铁，metallic=1\text{metallic} = 1metallic=1）：
    • 金属内部的自由电子会吸收折射进入内部的电磁波，因此纯金属无次表面漫反射（kd=0k_d = 0kd​=0）。
    • 金属的垂直基础反射率 F0F_0F0​ 较高（0.5∼0.980.5 \sim 0.980.5∼0.98）且具有波长选择性（有色高光）。在金属度工作流中，直接复用 BaseColor 贴图存储金属的有色 F0F_0F0​。
  3. Shader 统一插值与能量守恒代码实现：
    HLSL
    // 1. 根据金属度在非金属常数 0.04 与金属有色 BaseColor 之间插值得到 F0
float3 F0 = lerp(float3(0.04, 0.04, 0.04), baseColor.rgb, metallic);

// 2. 计算菲涅尔反射比例 F（即镜面反射拿走的能量比例 ks = F）
float3 F = F_Schlick(max(dot(H, V), 0.0), F0);

// 3. 严格能量守恒：折射进入内部的比例为 (1.0 - F)，且纯金属无漫反射故再乘以 (1.0 - metallic)

// 4. 最终单光源直接光照出射 Radiance
float3 Lo = (kd * baseColor.rgb / PI + specularBRDF) * lightRadiance * NdotL;

第 3 章：基于图像的光照（IBL）与 Epic Split-Sum 拆解近似#

基于图像的光照（Image-Based Lighting, IBL）将包围场景的高动态范围全景贴图（HDR Cubemap）视为连续球面光源，通过对环境贴图求解半球积分提供间接环境漫反射与环境镜面反射。

3.1 漫反射 IBL：辐照度环境图（Irradiance Map）与球谐光照（SH）#

在反射方程的漫反射部分中，由于 Lambertian 项 kd(c/π)k_d (\mathbf{c} / \pi)kd​(c/π) 与入射方向 ωi\omega_iωi​ 无关（或将 kdk_dkd​ 近似替换为粗糙度修正菲涅尔 1−Froughness(n,v)1 - F_{\text{roughness}}(\mathbf{n}, \mathbf{v})1−Froughness​(n,v)），可以将其直接提取到半球积分号外面：

  • 离线烘焙方案 A（Irradiance Cubemap）：在离线阶段遍历一个低分辨率（如 32×32×632 \times 32 \times 632×32×6）Cubemap 的每个纹素方向作为法线 n\mathbf{n}n，对原始高清 HDR 环境图执行半球余弦加权卷积积分并存入该纹素；运行时片元着色器只需以世界法线 N\mathbf{N}N 执行 1 次 texCUBE(irradianceMap, N) 采样即可拿到全场漫反射环境光。
  • 离线烘焙方案 B（二阶球谐函数 Spherical Harmonics, SH）：由于余弦卷积后的漫反射辐照度变化平缓（主要由低频信号组成），Unity 与 Unreal 的 Light Probes 直接将其投影到前 3 阶（l=0,1,2l = 0, 1, 2l=0,1,2，共 1+3+5=91 + 3 + 5 = 91+3+5=9 个基函数）球谐函数系数上——每个光照探针只需存储 9 个 RGB 向量（27 个浮点数），运行时通过简单的多项式点积即可极速还原任意法线方向的漫反射环境光。

第 4 章：实时阴影技术：Shadow Map、PCF、PCSS 与 CSM 级联阴影#

4.1 Shadow Mapping 两趟原理与自阴影走样（Shadow Acne vs Peter Panning）#

经典的 Shadow Mapping（阴影映射，Williams 1978） 算法分为两个渲染 Pass：

  1. Shadow Caster Pass（光源视角深度渲染）：将虚拟相机放置于光源位置，将场景几何体变换到光源裁剪空间，仅向一张深度纹理（Shadow Map）写入离光源最近的片元深度值 zmapz_{\text{map}}zmap​。
  2. Main Lighting Pass（主相机视角阴影比对）：渲染主相机画面时，将每个片元的世界坐标 PworldP_{\text{world}}Pworld​ 乘以光源矩阵变换到光源空间，得到该片元距离光源的实际深度 zcurz_{\text{cur}}zcur​ 以及在 Shadow Map 上的采样坐标 (u,v)(u, v)(u,v)；若 zcur>zmap(u,v)z_{\text{cur}} > z_{\text{map}}(u, v)zcur​>zmap​(u,v)，说明该点在光源方向上被更近的物体挡住，判定处于阴影中。

  • 自阴影条纹（Shadow Acne）的成因： 因为 Shadow Map 的纹素分辨率有限，每个纹素覆盖场景中的一小块矩形面积；当光线倾斜照射平面时，平面上共享同一个 Shadow Map 纹素的多个屏幕片元中，有一半片元的真实深度 zcurz_{\text{cur}}zcur​ 比纹素中心记录的离散深度 zmapz_{\text{map}}zmap​ 稍大，另一半稍小，从而导致平面被自己遮挡、浮现出规则的明暗摩尔条纹。
  • 斜率自适应偏移（Slope-Scale Depth Bias）与法线偏移（Normal Bias）： 光线与表面法线夹角 θ\thetaθ 越大（表面越陡峭），纹素跨度引起的深度误差 Δz∝tan⁡θ\Delta z \propto \tan\thetaΔz∝tanθ 越大。因此不能使用固定常数偏移，而必须根据 N⋅L\mathbf{N} \cdot \mathbf{L}N⋅L 动态调节偏移量：
    HLSL
    float bias = max(slopeScaleBias * (1.0 - dot(N, L)), minConstantBias);
    同时需控制 bias 上限：若深度偏移过大，物体与地面接触处的地面深度被过度减小，会导致本应在阴影中的接触面逃脱阴影判定，产生阴影与角色脚底脱节悬浮的伪影（Peter Panning）。Unity URP 通过结合沿法线向内微缩采样坐标（Normal Bias）与适度深度偏移共同消除上述两类伪影。

4.2 PCF 抗锯齿滤波与 PCSS 接触硬化软阴影#

  1. PCF（Percentage-Closer Filtering，百分比渐近滤波）：
    • 注意：不能对 Shadow Map 的深度值直接做双线性插值后再比较（先平均深度再比较仍会得到非 0 即 1 的硬边界）。
    • 正确做法：在当前片元对应的 Shadow Map (u,v)(u, v)(u,v) 周围（如 3×33 \times 33×3 或 Poisson Disk 圆盘采样核）采样 KKK 个邻近纹素，分别将 zcurz_{\text{cur}}zcur​ 与这 KKK 个深度值逐一做大小比较得到 KKK 个 0/10/10/1 可见性结果，最后对这 KKK 个 0/10/10/1 结果求加权平均，得到平滑过渡的半影灰度值 visibility∈[0,1]\text{visibility} \in [0, 1]visibility∈[0,1]。
  2. PCSS（Percentage-Closer Soft Shadows，Fernando 2005）： 真实世界中面光源产生的阴影具有显著的接触硬化（Contact Hardening）现象：遮挡物（如树枝或脚底）离受影地面越近，阴影边缘越锐利清晰；离受影地面越远，半影区（Penumbra）越宽、阴影越模糊柔和。固定核半径的 PCF 无法模拟这一物理现象，PCSS 通过三步动态计算滤波核半径：
    • 第一步（Blocker Search 遮挡物平均深度搜索）：在当前片元 (u,v)(u, v)(u,v) 邻域内采样若干点，找出所有比当前片元深度 dreceiverd_{\text{receiver}}dreceiver​ 更浅（即 zmap<dreceiverz_{\text{map}} < d_{\text{receiver}}zmap​<dreceiver​）的有效遮挡点，求其算术平均深度 dblockerd_{\text{blocker}}dblocker​（若无任何遮挡点则直接提前终止返回完全照亮 1.01.01.0）。
    • 第二步（Penumbra Size 半影宽度估算）：设面光源尺寸为 wlightw_{\text{light}}wlight​，根据相似三角形比例直接算出半影区半径：
      wpenumbra=(dreceiver−dblocker)⋅wlightdblockerw_{\text{penumbra}} = \frac{(d_{\text{receiver}} - d_{\text{blocker}}) \cdot w_{\text{light}}}{d_{\text{blocker}}}wpenumbra​=dblocker​(dreceiver​−dblocker​)⋅wlight​​
    • 第三步（可变核半径 PCF 采样）：将算出的 wpenumbraw_{\text{penumbra}}wpenumbra​ 作为 Poisson 圆盘 PCF 的采样扩散半径，执行百分比渐近滤波。

4.3 CSM（Cascaded Shadow Maps，级联阴影贴图）与防抖动对齐#

在开放世界或大尺度室外场景中，平行太阳光需要覆盖从相机前 0.1 m0.1\text{ m}0.1 m 到远方 500 m500\text{ m}500 m 的广阔区域。若仅用单张 2048×20482048 \times 20482048×2048 的 Shadow Map 包围整个视锥体，平均每个阴影纹素在地面上要跨好几米，导致玩家眼前的角色阴影呈现严重的马赛克锯齿（透视走样 Perspective Aliasing）。

  • CSM 视锥分段级联原理：
    1. 对数 + 均匀混合切分视锥体：将主摄像机视锥体沿观察深度方向切分为 3∼43 \sim 43∼4 个子视锥体（Cascades，例如按 7%/15%/30%/48%7\% / 15\% / 30\% / 48\%7%/15%/30%/48% 比例切分为 [0.1 m∼15 m][0.1\text{ m} \sim 15\text{ m}][0.1 m∼15 m]、[15 m∼45 m][15\text{ m} \sim 45\text{ m}][15 m∼45 m]、[45 m∼120 m][45\text{ m} \sim 120\text{ m}][45 m∼120 m]、[120 m∼300 m][120\text{ m} \sim 300\text{ m}][120 m∼300 m]）：
      di=λ⋅n(fn)i/m+(1−λ)(n+im(f−n))d_i = \lambda \cdot n \left(\frac{f}{n}\right)^{i / m} + (1 - \lambda)\left(n + \frac{i}{m}(f - n)\right)di​=λ⋅n(nf​)i/m+(1−λ)(n+mi​(f−n))
    2. 独立正交包围盒渲染：为每一级子视锥体单独计算光源方向下的紧凑正交投影包围盒，分别渲染进同一张阴影图集的 4 个象限（或 Texture2DArray 的 4 个 Slice，每级各享 2048×20482048 \times 20482048×2048 分辨率）。这样近处 Cascade 0 的纹素密度极高，远景 Cascade 3 又能覆盖全场。
    3. 级联接缝平滑混合（Cascade Blending）：在相邻两级 Cascade 交界处的过渡带（如 10% 宽度）内，同时采样前后两级 Shadow Map 并按距离线性插值，消除级联切换处的硬突变分界线。
  • 相机移动或旋转时 CSM 阴影边缘闪烁（Shadow Shimmering）的成因与稳定化方法：
    • 原因：当主相机微移或旋转时，如果每帧重新根据子视锥体 8 个角点计算紧凑轴对齐包围盒（AABB），光源正交投影框的宽高尺寸和中心坐标会随帧连续微变，导致世界空间中的固定物体在 Shadow Map 纹素网格上不断错位滑动，引发阴影边缘高频闪烁。
    • 两步稳定化方法：
      1. 使用固定半径的球体包围盒（Bounding Sphere）替代 AABB：子视锥体对应的最小外接球半径在相机任意旋转下恒定不变，从而锁死光源正交投影矩阵的缩放尺寸。
      2. 世界空间纹素步长对齐（Texel Snapping）：计算光源空间下单个 Shadow Map 纹素对应的世界宽度 worldUnitsPerTexel=Wortho/Rmap\text{worldUnitsPerTexel} = W_{\text{ortho}} / R_{\text{map}}worldUnitsPerTexel=Wortho​/Rmap​，将光源相机在 XYXYXY 平面上的平移坐标强制向下取整对齐到纹素步长的整数倍网格点上（pos.xy = floor(pos.xy / worldUnitsPerTexel) * worldUnitsPerTexel），使相机移动时阴影纹素在世界空间中保持绝对静止。
