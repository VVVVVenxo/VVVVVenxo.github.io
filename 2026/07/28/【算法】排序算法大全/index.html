【算法】排序算法大全

前言

排序是算法学习的基础。衡量一个排序算法通常看四个指标：

  • 时间复杂度：算法执行所需的时间量级
  • 空间复杂度：算法执行需要的额外辅助空间
  • 是否稳定：交换位置后，相等元素之间的相对位置是否保持不变
  • 是否原地：是否需要消耗额外的辅助空间进行排序

下面按从简单到复杂的顺序，逐一梳理八大排序算法。

一、选择排序

原理：不断选择数组中最小的元素，然后与 sortedIndex 位置的元素交换。

  • 平均时间复杂度：O(n²)
  • 空间复杂度：O(1)
  • 不是稳定排序——因为存在直接交换操作，可能改变相等元素的相对位置。

二、冒泡排序

原理：从前往后两两比较，逆序则交换，不断重复直到整个序列有序。

  • 平均时间复杂度：O(n²)
  • 最好时间复杂度：O(n)（序列已有序时）
  • 是稳定排序。

三、插入排序

原理：将序列分为「排序区」和「未排序区」两个区域，用一个索引值作分水岭。不断取出未排序区的元素，与排序区元素比较，插入到合适位置，直到未排序区清空。

  • 平均时间复杂度：O(n²)，最好情况 O(n)
  • 空间复杂度：O(1)
  • 是稳定排序。

套路写法：两层循环，外层获取未排序区元素，内层找到合适的插入位置。

四、希尔排序

插入排序的升级版。核心思想是分阶段进行：设置一个步长 n，先排序好每隔 n 步长的数字，然后逐步减小步长直到 1。这样首次将时间复杂度突破了 O(n²)。

  • 平均时间复杂度：O(nlogn)
  • 空间复杂度：O(1)

套路写法：三层循环——第一层获取步长，第二层获取未排序元素，第三层找到合适位置插入。

五、归并排序

灵感来源于二叉树的后序遍历：一开始不会执行排序，要先递归拆分到最小容量数组时，才会回头调用 Sort 进行合并排序。

  • 平均时间复杂度：O(nlogn)
  • 空间复杂度：O(n)（需要消耗额外的辅助空间）
  • 是稳定排序。

核心公式：归并 = 递归 + 合并。

六、快速排序

灵感来源于二叉树的前序遍历。

  • 平均时间复杂度：O(nlogn)
  • 最坏时间复杂度：O(n²)
  • 空间复杂度：O(logn)

为什么快排常常比堆排序快？ 快速排序每一步访问的数据都是连续的，而堆排序需要不停比较父子节点（父节点为 N，子节点为 2N+1），两者在内存中相距较远。快速排序有更好的局部性，所以虽然两者理论平均复杂度相同，但实际运行时快排往往大幅优于堆排序。

归并 vs 快排：

  • 相同点：都用到递归，都会把数组分成几部分。
  • 不同点：归并排序递归过程中会不停产生新数组用于合并，快排不会产生新数组；归并是拆分完毕后再排序，快排是边排序边拆分。

七、堆排序

  • 平均时间复杂度：O(nlogn)
  • 空间复杂度：O(1)

关键规则：

  • 最大非叶子节点索引：数组长度 / 2 - 1
  • 父节点 i，左节点 2i+1，右节点 2i+2

注：构建大顶堆应从「最大非叶子节点」数组长度 / 2 - 1 开始向前遍历，这样才能保证自底向上完成堆化。

八、计数排序

计数排序不依赖元素之间的比较，而是通过统计每个数出现的次数，再按数值大小顺序「还原」出排序后的结果。它利用的是键值有限、可直接映射到数组下标的特性，从而避免了两两比较。

因此计数排序在数据范围不大时能达到接近 O(n) 的线性时间，但当数值范围很大时会浪费大量空间。

总结

排序算法 平均时间复杂度 空间复杂度 是否稳定
选择排序 O(n²) O(1) 否
冒泡排序 O(n²) O(1) 是
插入排序 O(n²) O(1) 是
希尔排序 O(nlogn) O(1) 否
归并排序 O(nlogn) O(n) 是
快速排序 O(nlogn) O(logn) 否
堆排序 O(nlogn) O(1) 否
计数排序 O(n+k) O(k) 是

关于 STL 的排序：C++ 的 sort 综合使用了快速排序、插入排序和堆排序——数据量大时用快排，划分区段较小时用插入排序，当划分有导致最坏情况的倾向时切换为堆排序。
